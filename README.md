# NPCLife

**LLM 驱动的游戏叙事中间件**

NPCLife 是一个可嵌入游戏引擎的 C# 库。游戏事件不再被预先"编剧"，而是在 NPC 即将开口的瞬间（话语时刻）按需装配材料、由唯一的热路径 LLM——写手——生成台词。

---

## 核心思想

> 叙事需要的是"玩家视野与 NPC 思维的对齐"——这是在消费时刻（NPC 开口时）才结账的**投影问题**，而不是事件产生时的**分区问题**。

因此：

- **无剧情线 / 工作空间**：事件不预分配归属，只在被消费时才做语义结账；
- **热路径零生成式路由**：事件摄入与材料筛选全程无 LLM；
- **成本 ∝ 消费**：没有话语时刻就没有任何生成开销，无人问津的事件零成本。

```
宿主事件 ──▶ 采集层(机械标注) ──▶ 事件流(append-only + 索引)
                                       │
                                       │ 机械过滤
话语时刻 ──▶ 材料装配 ◀── 视锥过滤器 ─────┘
(宿主上报)     │         V_p 玩家视锥 / K_n NPC 认知视锥
              │  判别器(确定性特征打分，零模型)
              ▼
          材料袋(三区材料 + 话语记忆 + 知识锚点)
              │
              ▼
        写手(唯一热路径 LLM，Tier 0/1/2 分层渲染)
              │
              ▼
        投递车道 ──▶ 游戏侧消费 ──▶ 话语记忆(防重复/连续性)
```

## 它能做什么

### 按需台词生成

宿主在玩家与 NPC 对话、事件叫喊、信件附言或环境脉冲时上报**话语时刻**（`MomentKind`：Interaction / Bark / Letter / AmbientPulse）。管线现场完成：

1. **视锥投影**：把事件切成三区——`K∩V` 共同经历（回响）、`K\V` NPC 独知（信息投放）、`V\K` 玩家独知（认知边界，防全知幻觉）；
2. **判别器打分**：确定性特征线性打分（时间邻近 / actor 重叠 / Importance / 未提及度），按预算截断装入**材料袋**；
3. **写手生成**：单次 LLM 调用把材料袋写成人格一致的台词；Tier 闸门按显著度决定实际花费（Tier 0 模板 = 0 次调用，Tier 1 缓存 = 0~1 次，Tier 2 全量 = 1 次）。

### 职责边界与降级

- 写手只能使用袋内材料（袋外事实禁止），可脑补袋内断链、过滤噪声；
- 任何单点缺失只降粒度不断流：视锥不齐 → 粗视锥；标注缺失 → 合成句柄；写手超时 → Tier 0 模板兜底；
- 伏笔采用**机械 open-loops 清单** + 写手顺带 plant/callback；离线伏笔规划器为可选第二 LLM，默认关闭（本库不含其实现）。

### 离线质量保障

回放评估器（`ReplayEvaluator`，非 AI）重放历史事件流，输出 bag 召回率、成本曲线与 Tier 分布，作为回归基线供手工阈值离线校准——系统内没有任何在线学习回路。

## 集成方式

NPCLife 是纯逻辑库（net48 / netstandard2.0），不依赖任何游戏引擎。宿主游戏需要提供：

- **存储适配器**（`IStorage` / `ICacheStore`）：事件流与知识缓存持久化
- **日志适配器**（`ILogger`）：框架日志输出
- **LLM 服务**（`ILlmService` / 凭证体系）：对接 OpenAI 兼容 API（写手唯一复用）
- **时间/交互信号**：上报话语时刻与交互流水（`IInteractionStore`，供听闻传播）
- **台词消费者**（`IScriptConsumer`）：游戏侧接收 `ScriptLine` 并显示（主线程投递）

知识词条由宿主经 `IKnowledgeService` 检索后，作为专名锚点随材料袋传入（见 `docs/KnowledgeModule.md`）。

完整设计见 `docs/AlignmentPipeline/`（原理推导 / 目标架构 / 迁移记录 / 决策与开放问题）。

## 适用场景

- 需要 NPC 台词响应玩家行为与世界变化、但成本须与内容消费挂钩的游戏
- 希望对话"记得住"（话语记忆防重复、三区认知边界防穿帮）的沙盒/殖民地模拟类游戏
- 开发者能够注入自己的存储、日志、LLM 服务实现
